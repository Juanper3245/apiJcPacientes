# CRUD de Pacientes con JavaScript y Bootstrap 5

Implementación directa de las 5 operaciones sobre la API de Pacientes:

1. **Listar pacientes** (`GET /api/listar.php`)
2. **Ver paciente por ID** (`GET /api/ver.php?id={id}`)
3. **Crear paciente** (`POST /api/crear.php`)
4. **Actualizar paciente** (`POST /api/actualizar.php`)
5. **Eliminar paciente** (`POST /eliminar.php`)
